# 报名录屏建议（约60–90秒）
1. 桌面浏览器打开 http://127.0.0.1:8000，保持全域视图，展示管段数、长度与风险分布。
2. 在中央地图切换“道路类型”，展示与管网总览图一致的几何分布；再切回“风险等级”。
3. 放大地图，点击一条管线，展示编号、评分及属性更新；可使用“定位”查看选中管段。
4. 在检索框输入“解放路”并应用筛选，展示空间与统计联动；演示完点击重置。
5. 打开“管段台账”，勾选需要排查的管段，导出清单。
6. 最后打开“数据说明”，说明当前接入的是提供资料与既有评分，训练模型后续替换。

讲解可用：已完成管网空间与属性资料整合、交互查询、资料风险分级和排查清单输出；后续接入训练模型预测与解释结果。
不要把资料评分称为已训练模型准确率，也不要把属性观测称为已验证根因。
录制前关闭与任务无关的标签页与弹窗，避免出现学校名称或校徽。
本文件是录屏脚本建议，不是已生成的视频。
