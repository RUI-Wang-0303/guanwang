# 第一个练习：在档案中显示“道路类型”
当前资料已经有 road_type 字段。
1. 打开 frontend/src/App.vue，找到显示管径、管材的 dl。
2. 加入：<div><dt>道路类型</dt><dd>{{ active.road_type || '未提供' }}</dd></div>
3. 在 frontend/ 执行 npm.cmd run dev，用5173端口页面查看；若用8000端口，先执行 npm.cmd run build 再刷新。
4. 点击不同管段，观察资料是否同步。不要修改原始表格。
5. 理解：该字段已在接口中，因此只需改展示；新字段若不在接口内，需同时调整导入脚本与后端返回内容。

选中流程：Canvas识别最近线段 → pipe-select(ID) → App更新selectedId → GET /api/pipes/{ID} → 更新档案。
