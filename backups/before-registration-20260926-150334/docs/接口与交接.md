# 数据与地图交接约定
## API
- GET /api/health：服务状态与 demo 标识。
- GET /api/dashboard：返回 meta、filters、summary、pipes。
- GET /api/pipes/{pipe_id}：单管段；不存在返回 404。
- GET /api/export：当前结果 CSV，或指定 ids（英文逗号分隔）。
列表和导出共用 q、risk（空/高/中/低）、material、min_diameter 筛选；按风险分降序。
统计仅针对本次筛选结果。材料选项来自完整数据。详情目前直接使用列表中的记录；独立详情 API 已为后续大量数据预留。

## 最小管段字段
pipe_id（唯一字符串）、road、diameter_mm（数字，mm）、material、age_years（年）、length_m（m）、risk_score（0–100演示分）、risk_level（高/中/低）、factors（字符串数组）、recommendation（字符串）。
现在 factors 与 recommendation 是示例，后续须由模型/业务负责人交付真实依据。不能由界面猜测事故原因或处置措施。
meta 包含 mode、as_of、model_version。接入前确认评估时间与数据时间、评分定义、等级阈值；样例阈值不是行业标准。概率另设字段并明确预测窗口，不能把分数除以100后当概率。

## 地图组件约定
文件 frontend/src/components/PipeMap.vue。
接收 props：pipes（当前筛选管段数组）、selectedId（字符串）、filters（筛选控件当前值；以 pipes 为实际显示结果）。
发出事件：pipe-select，参数为选中管段的字符串 pipe_id。
demo_path 和 demo_label 仅用于 SVG 示意图，不能转成真实经纬度。
替换为 GIS 时保留 props/事件，将空间 geometry 放在独立 GeoJSON 中，并用 pipe_id 关联业务结果。确认坐标系后进行正确转换，禁止直接猜测或覆盖坐标系定义。
地图与风险结果未匹配的管段应显示“未评估”，不能归为低风险。
道路图层须单独明确来源；管段属性中的道路类型不等于真实道路几何。
将真实数据接入后，一并修改页面数据来源、mode 标识、空值显示与分级规则。不要只去掉演示标签。
