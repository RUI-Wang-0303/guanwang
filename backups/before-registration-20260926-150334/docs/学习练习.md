# 第一个练习：给详情增加“所在区域”
目标：理解后端数据如何进入页面。
1. 在 demo_data/pipes.json 的每条管段记录中增加 "region": "演示北区" 等虚构区域。
2. 在 frontend/src/App.vue 中找到显示“管龄”和“长度”的 dl，在其中加入：
```html
<div><dt>所在区域</dt><dd>{{ active.region || '待提供' }}</dd></div>
```
3. 重启 Python 服务，使用 Vite 开发页面，点击不同管段查看区域变化。
4. 想一想：为什么本例无需修改 backend/main.py？因为接口直接返回记录里的字段。未来若后端使用严格的响应模型，就还需要扩展响应模型。
5. 扩展练习：将新字段加入 CSV 表头和对应行，确认列顺序一致。

## 理解四个核心概念
- ref：Vue 用来保存会变化的值，例如 selectedId。
- computed：从现有值推导结果，例如 active 根据 selectedId 找出管段。
- fetch：浏览器向 /api/dashboard 请求 JSON。
- emit：地图告诉父页面“某条管段被选中了”，它自己不承担详情面板业务。

## 手动验收
启动后应有12条演示管段。点 DEMO-009，右侧显示91分且为高风险。
筛选“高”：4条。再选最小DN1000：2条。

重置后勾选两条并导出：CSV包含两条数据行，带“虚构演示数据”。
Tab聚焦示意管线后按回车，应和鼠标点击一样更新详情。
